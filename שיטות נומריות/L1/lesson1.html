1. מבוא לפתרון נומרי של משוואות לא לינאריות

יעד: הגדרת בעיית מציאת שורש f(x) = 0

בחיים האמיתיים ובמחשבים, לרוב המשוואות הלא-לינאריות אין נוסחה אלגברית סגורה למציאת הפתרון המדויק. לכן נדרש פתרון נומרי מקורב.

  • מטרת העל: למצוא את השורש אלפא עבורו f(x) = 0, כאשר f היא פונקציה לא לינארית.
  • העיקרון האיטרטיבי: מתחילים מניחוש התחלתי x0, ומפעילים חוק חזק המייצר סדרת קירובים עוקבים x1, x2, x3 ואילך המתקרבים אל השורש המבוקש.

2. שיטות איטרטיביות והבחנה בין התכנסות להתבדרות

יעד: בידוד x והבחנה בין G(x) מתכנסת לשגגויה

מתוך משוואה מבוקשת f(x) = 0, מבצעים מניפולציה אלגברית כדי להביאה לצורת נקודת שבת: x = G(x). לא כל דרך בידוד מביאה להתכנסות!

מוסר השכל מרכזי: בחירת G(x) לא נכונה עלולה להכניס את החישוב למעגל אינסופי קפוא ולא מתכנס.

דוגמה 1: מניפולציה מתכנסת עבור x^2 - 5 = 0

נבודד את x: משוואה x^2 + x = 5 + x מובילה ל- x(x+1) = 5+x, כלומר x = (5+x) / (x+1).

הפונקציה האיטרטיבית: G1(x) = (5+x) / (x+1).

הרצה מהניחוש x0 = 2:

  • x1 = G1(2) = 7 / 3 בקירוב 2.333
  • x2 = G1(2.333) = 7.333 / 3.333 בקירוב 2.2
  • x3 = G1(2.2) = 7.2 / 3.2 בקירוב 2.25

מסקנה: המספרים מתכנסים אל הפתרון האמיתי שורש 5 בקירוב 2.236.

דוגמה 2: מניפולציה מתבדרת (כשל) עבור x^2 - 5 = 0

נחלק ב-x: משוואה x^2 = 5 מובילה ל- x = 5 / x.

הפונקציה האיטרטיבית: G2(x) = 5 / x.

הרצה מהניחוש x0 = 2:

  • x1 = G2(2) = 5 / 2 = 2.5
  • x2 = G2(2.5) = 5 / 2.5 = 2
  • x3 = G2(2) = 2.5

מסקנה: התהליך נתקע במעגל 2 עובר ל-2.5 עובר ל-2 וחוזר חלילה, ואינו מתכנס!

3. הגדרות פורמליות: התכנסות, שגיאה וסדר התכנסות

יעד: הגדרת השגיאה en וקצב התכנסות p
  • התכנסות לפתרון: שאיפה בגבול כאשר n שואף לאינסוף של xn שווה לאלפא.
  • הגדרת השגיאה באיטרציה ה-n: en = |אלפא - xn|.
  • סדר התכנסות p: שיטה היא מסדר p אם מתקיים עבור קבוע c כי |en+1| קטן או שווה ל-c כפול (en בחזקת p).

משמעות קצב ההתכנסות:

עבור p = 1 (התכנסות לינארית), השגיאה קטנה ביחס קבוע בערך בכל צעד.

עבור p = 2 (התכנסות ריבועית), השגיאה קטנה ביחס לריבוע השגיאה הקודמת, מה שמכפיל את כמות הספרות המדויקות בכל צעד!

4. שיטת החצייה (Bisection Method) - אלגוריתם פורמלי

יעד: הבנת אלגוריתם החצייה וצימצום הקטע

מבוססת על משפט ערך הביניים: אם הפונקציה f(x) רציפה בקטע הסגור בין a ל-b ומתקיים f(a) כפול f(b) קטן מאפס, מובטח שורש בקטע.

  1. מגדירים קטע התחלתי [a, b] עם סימנים מנוגדים ודיוק רצוי דלתא גדול מ-0.
  2. מחשבים את נקודת האמצע: c = (a + b) / 2.
  3. בודקים תנאי עצירה: אם אורך הקטע |b - a| קטן מדלתא, עוצרים ו-c הוא השורש המקורב.
  4. עדכון קצוות: אם f(a) כפול f(c) קטן או שווה לאפס, מעדכנים את b = c. אחרת, מעדכנים את a = c, וחוזרים לשלב 2.

5. תנאי עצירה (Stopping Criteria) והבחנה קריטית

יעד: הבחנה בין הפרש x-ים לערך f(x)

קיימים שני תנאי עצירה מרכזיים. אזהרה: אין לבלבל בין גובה הפונקציה f(x) לבין הפרש הקירובים של x!

  • תנאי 1 (הפרש קירובי x): |cn - cn-1| קטן או שווה לאפסילון.
  • תנאי 2 (ערך הפונקציה): |f(cn)| קטן או שווה לאפסילון.

דוגמה: תנאי עצירה מתקיים

עבור דיוק מבוקש אפסילון = 0.01:

אם cn = 2.15 ו-cn-1 = 2.14, מתקיים: |2.14 - 2.15| = 0.01 קטן או שווה ל-0.01.

מסקנה: עוצרים בבטחה!

דוגמה: תנאי עצירה לא מתקיים

עבור דיוק מבוקש אפסילון = 0.01:

אם cn = 2.155 ו-cn-1 = 2.14, מתקיים: |2.14 - 2.155| = 0.015 גדול מ-0.01.

מסקנה: אסור לעצור! חובה להמשיך לאיטרציה הבאה.

6. תרגיל בית/בחינה מלא: הוכחת קיום, יחידות וטבלת 10 איטרציות

יעד: פתרון מלא של שאלה מקיפה מהמחברת

השאלה מתוך המחברת: הוכח כי למשוואה e^(2x) + 3x + 1 = 0 קיים פתרון יחיד בקטע בין מינוס 5 ל-5, ומצא את הקירוב בשיטת החצייה עד שגיאה קטנה מ-0.01.

חלק א': הוכחת קיום ויחידות הפתרון

1. הוכחת קיום (משפט ערך הביניים):

הפונקציה f(x) = e^(2x) + 3x + 1 רציפה בקטע [-5, 5].

f(-5) = e^(-10) - 15 + 1 = e^(-10) - 14 בקירוב -13.999 שזה קטן מאפס.

f(5) = e^(10) + 15 + 1 = e^(10) + 16 בקירוב 22042.46 שזה גדול מאפס.

מכיוון ש-f(-5) כפול f(5) קטן מאפס, לפי משפט ערך הביניים קיים לפחות שורש אחד בקטע [-5, 5].


2. הוכחת יחידות (נגזרת ומונוטוניות):

הנגזרת f'(x) = 2e^(2x) + 3. מכיוון ש-e^(2x) תמיד חיובי, הנגזרת גדולה מ-3 ולכן חיובית ממש לכל x בקטע.

לכן הפונקציה מונוטונית עולה ממש בכל הקטע, ומכאן שהפתרון הוא פתרון יחיד!
