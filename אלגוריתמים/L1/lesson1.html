1. חזרה: מה זו סיבוכיות ואיך מחשבים אותה

יעד: חישוב סיבוכיות וסימוני O, Omega, Theta

לא מודדים זמן ריצה בשניות כי הוא תלוי במחשב, אלא סופרים פעולות בסיסיות (צעדים) כפונקציה של גודל הקלט n. מתעלמים מקבועים ומאיברים קטנים.

  • סדר גדילה (מהאיטי למהיר): 1 < log n < √n < n < n log n < n2 < n3 < 2n < n!
  • סימונים אסימפטוטיים: O (חסם עליון), Ω (חסם תחתון), Θ (חסם הדוק).
  • לולאות: ברצף מחברים, בלולאות מקוננות כופלים. לולאה שמחלקת ב-2 נותנת Θ(log n).

2. הרעיון של הפרד ומשול (Divide and Conquer)

יעד: שלושת השלבים ונוסחת נסיגה

שיטה לפתרון בעיות על ידי פירוקן לתתי-בעיות קטנות:

  1. הפרד (Divide): חלוקת הבעיה לתתי-בעיות קטנות מאותו סוג.
  2. משול (Conquer): פתרון כל תת-בעיה ברקורסיה.
  3. צרף (Combine): חיבור הפתרונות לפתרון כולל.

נוסחת נסיגה כללית: T(n) = a · T(n/b) + f(n).

3. חיפוש בינארי (Binary Search)

יעד: אלגוריתם חיפוש במערך ממוין בצורה יעילה

בכל שלב משווים את הערך המבוקש לאמצע המערך, וזורקים חצי מהנתונים.

  • סיבוכיות: T(n) = T(n/2) + 1, והפתרון הוא Θ(log n).
  • תנאי הכרחי: המערך חייב להיות ממוין.

דוגמה לחיפוש בינארי

במערך של 1,000,000 איברים, חיפוש בינארי ידרוש לכל היותר כ-20 השוואות בלבד (לעומת מיליון בחיפוש רגיל)!

4. מיון מיזוג (Merge Sort)

יעד: מיון יעיל בשיטת הפרד ומשול

חותכים את המערך לחצאים, ממיינים כל חצי ברקורסיה, וממזגים את החצאים הממוינים למערך אחד מושלם.

  • נוסחת נסיגה: T(n) = 2T(n/2) + n.
  • סיבוכיות: Θ(n log n).
  • חיסרון בולט: דורש זיכרון נוסף לצורך המיזוג (Θ(n)).

5. שיטת האיטרציה (פתיחת הנוסחה)

יעד: פתרון נוסחאות נסיגה ידנית

מתכון פשוט לפתיחת נוסחאות נסיגה ידנית:

  1. מציבים את הנוסחה בתוך עצמה 2-3 פעמים.
  2. מזהים תבנית כללית לאחר k הצבות.
  3. מוצאים מתי מגיעים לבסיס הרקורסיה (n = 1).
  4. מציבים ומפשטים בעזרת סכומים מוכרים (כמו סדרה חשבונית או הנדסית).

6. משפט המאסטר (Master Theorem)

יעד: פתרון מהיר לנוסחאות נסיגה

נוסחה מוכנה למציאת סיבוכיות של נוסחאות מהצורה T(n) = a · T(n/b) + f(n) בלי פתיחה ידנית:

  • מקרה 1 (העלים מנצחים): אם f(n) קטנה פולינומית מ-nlogb a, אז T(n) = Θ(nlogb a).
  • מקרה 2 (תיקו): אם f(n) שווה בסדר גודל ל-nlogb a, אז T(n) = Θ(nlogb a · log n).
  • מקרה 3 (השורש מנצח): אם f(n) גדולה פולינומית מ-nlogb a ובכפוף לתנאי הרגולריות, אז T(n) = Θ(f(n)).

דוגמה מעשית לשימוש במשפט המאסטר (מיון מיזוג)

נתונה נוסחת הנסיגה של אלגוריתם מיון מיזוג:

T(n) = 2T(n/2) + n

  1. זיהוי הפרמטרים: a = 2, b = 2, ו-f(n) = n.
  2. חישוב מספר העלים: nlog2 2 = n1 = n.
  3. השוואה (תחרות): העבודה בעלים היא n והעבודה בשורש היא f(n) = n. שניהם שווים (n מול n), ולכן זהו מקרה 2 (תיקו).
  4. תוצאה סופית: מכיוון שמדובר במקרה 2, מכפילים ב-log n ומקבלים Θ(n log n).
