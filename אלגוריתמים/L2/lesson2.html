1. נוסחת הנסיגה הכללית של הפרד ומשול

The Paradigm

אלגוריתמים בשיטת הפרד ומשול (Divide and Conquer) מפרקים בעיה בגודל \(n\) לתת-בעיות קטנות יותר, פותרים אותן ברקורסיה וממזגים את התוצאות.

נוסחת הנסיגה הכללית מיוצגת על ידי:

\[ T(n) = D(n) + a \cdot T(n/b) + C(n) \]
  • \(D(n)\): הזמן הנדרש לחלוקת הבעיה (Divide).
  • \(a \cdot T(n/b)\): קריאה ברקורסיה ל-\(a\) תתי-בעיות, שכל אחת מהן בגודל \(n/b\).
  • \(C(n)\): הזמן הנדרש לצירוף/מיזוג הפתרונות (Combine).

במשפט המאסטר, מגדירים \(f(n) = D(n) + C(n)\) לקבלת הצורה הסטנדרטית: \(T(n) = a T(n/b) + f(n)\).

2. חזרה: משפט המאסטר (Master Theorem)

סיבוכיות אסימפטוטית

עבור נוסחת נסיגה מהצורה \(T(n) = a T(n/b) + f(n)\), מגדירים קבוע \(c = \log_b a\) המשקף את עבודת העלים:

  • Case 1 (Leaves win): אם \(f(n) = O(n^{c - \varepsilon})\), אז \(T(n) = \Theta(n^c)\).
  • Case 2 (A tie): אם \(f(n) = \Theta(n^c \cdot \log^k n)\), אז \(T(n) = \Theta(n^c \cdot \log^{k+1} n)\).
  • Case 3 (Root wins): אם \(f(n) = \Omega(n^{c + \varepsilon})\) ומתקיים תנאי הרגולריות \(a f(n/b) \le \delta f(n)\), אז \(T(n) = \Theta(f(n))\).

דוגמאות מתוך השקף:

1. מיון מיזוג: \(T(n) = 2T(n/2) + n\)

כאן \(a=2, b=2 \implies c = \log_2 2 = 1\). מכיוון ש-\(f(n) = n = \Theta(n^1)\), זהו Case 2 (תיקו) ולכן התוצאה היא \(\Theta(n \log n)\).


2. דוגמה נוספת: \(T(n) = 3T(n/2) + n^2\)

כאן \(a=3, b=2 \implies c = \log_2 3 \approx 1.585\). מכיוון ש-\(f(n) = n^2 = \Omega(n^{1.585 + \varepsilon})\), העבודה בשורש מנצחת (Case 3) ולכן התוצאה היא \(\Theta(n^2)\).

3. טבלת אלגוריתמים רקורסיביים שנלמדו

השוואת סיבוכיות

סיכום נוסחאות הנסיגה של האלגוריתמים שנלמדו בקורס:

אלגוריתם נוסחת נסיגה \(T(n)\) סיבוכיות סופית
Binary Search \(T(n/2) + \Theta(1)\) \(\Theta(\log n)\)
Merge Sort \(2T(n/2) + \Theta(n)\) \(\Theta(n \log n)\)
Min & Max (Divide & Conquer) \(2T(n/2) + 2\) \(\Theta(n)\) [בדיוק \(\frac{3n}{2} - 2\) השוואות]
Karatsuba (כפל מספרים) \(3T(n/2) + \Theta(n)\) \(\Theta(n^{\log_2 3}) \approx \Theta(n^{1.585})\)
Strassen (כפל מטריצות) \(7T(n/2) + \Theta(n^2)\) \(\Theta(n^{\log_2 7}) \approx \Theta(n^{2.81})\)

4. מציאת מינימום ומקסימום במערך

אופטימיזציה של השוואות

בשיטה הישירה (שתי לולאות נפרדות), מציאת המקסימום דורשת \(n-1\) השוואות ומציאת המינימום דורשת \(n-1\) השוואות, סך הכל \(2n - 2\) השוואות.

באמצעות הפרד ומשול (MinMax), נחלק את המערך לשני חצאים, נמצא מינימום ומקסימום בכל חצי, ונחבר בעזרת 2 השוואות בלבד:

MinMax(A, i, j): if j == i: return (A[i], A[i]) if j == i + 1: if A[i] < A[j]: return (A[i], A[j]) else: return (A[j], A[i]) k = floor((i + j) / 2) (m1, M1) = MinMax(A, i, k) (m2, M2) = MinMax(A, k + 1, j) return (min(m1, m2), max(M1, M2))

תרגילים בנושא MinMax:

א. מהי נוסחת הנסיגה ומספר ההשוואות המדויק באלגוריתם MinMax?

נוסחת הנסיגה היא \(T(n) = 2T(n/2) + 2\) עם תנאי בסיס \(T(2) = 1\).

\[ T(n) = \frac{3n}{2} - 2 \]

חסיכון של 25% במספר ההשוואות לעומת השיטה הישירה (\(2n - 2\)).

5. כפל מהיר של מספרים גדולים (Karatsuba)

אלגוריתם קראצובה

כפל מסורתי (Grade School) של שני מספרים בני \(n\) סיביות דורש זמן של \(\Theta(n^2)\).

אם נפצל כל מספר לחצי: \(X = a \cdot 2^m + b\) ו-\(Y = c \cdot 2^m + d\) (כאשר \(m = n/2\)), הכפל הנאיבי נותן 4 מכפלות: \(ac, ad, bc, bd\), שמובילות ל-\(T(n) = 4T(n/2) + \Theta(n) = \Theta(n^2)\).

הרעיון של קראצובה (3 מכפלות בלבד):

\[ P_1 = ac, \quad P_2 = bd, \quad P_3 = (a + b)(c + d) \] \[ ad + bc = P_3 - P_1 - P_2 \] \[ X \cdot Y = P_1 \cdot 2^{2m} + (P_3 - P_1 - P_2) \cdot 2^m + P_2 \]

תרגילים בנושא Karatsuba:

א. חשב את סיבוכיות זמן הריצה של קראצובה בעזרת משפט המאסטר

נוסחת הנסיגה היא \(T(n) = 3T(n/2) + \Theta(n)\).

לפי משפט המאסטר: \(a=3, b=2 \implies c = \log_2 3 \approx 1.585\).

\[ T(n) = \Theta(n^{\log_2 3}) \approx \Theta(n^{1.585}) \]

6. כפל מטריצות מהיר (אלגוריתם שטראסן)

Strassen's Algorithm

כפל מטריצות ישיר הינו בסיבוכיות \(\Theta(n^3)\). פיצול נאיבי של מטריצה ל-4 בלוקים נותן 8 מכפלות רקורסיביות: \(T(n) = 8T(n/2) + \Theta(n^2) = \Theta(n^3)\) (ללא שיפור).

אלגוריתם שטראסן מצליח לחשב את המטריצה בעזרת 7 מכפלות רקורסיביות בלבד (\(P_1, P_2, \ldots, P_7\)) וחיבורים/חיסורים בסיסיים.

תרגילים בנושא כפל מטריצות ושטראסן:

א. מהי נוסחת הנסיגה והסיבוכיות הסופית של אלגוריתם שטראסן?

נוסחת הנסיגה היא \(T(n) = 7T(n/2) + \Theta(n^2)\).

לפי משפט המאסטר (Case 1), כאשר \(c = \log_2 7 \approx 2.807\):
