1. הגדרת ערך המיקום (Order Statistic) ובעיית הבחירה

הגדרות יסוד

בהינתן קבוצה בת \(n\) איברים, ערך המיקום ה-\(i\) (באנגלית: \(i\)-th Order Statistic) הוא האיבר ה-\(i\) הקטן ביותר בקבוצה.

  • מינימום (\(i = 1\)): האיבר הקטן ביותר בקבוצה.
  • מקסימום (\(i = n\)): האיבר הגדול ביותר בקבוצה.
  • חציון / Median (\(i = \frac{n+1}{2}\)): האיבר האמצעי (כאשר \(n\) זוגי מבחינים בין חציון תחתון \(\lfloor \frac{n+1}{2} \rfloor\) לחציון עליון \(\lceil \frac{n+1}{2} \rceil\)).

הגדרה פורמלית של בעיית הבחירה (Selection Problem):

  • קלט: קבוצה \(A\) של \(n\) מספרים (לנוחות נניח שהם שונים זה מזה), ומספר שלם \(i\) המקיים \(1 \le i \le n\).
  • פלט: האיבר \(x \in A\) הגדול בדיוק מ-\(i-1\) איברים אחרים ב-\(A\).

2. פתרון נאיבי ומקרים פרטיים בזמן ליניארי

מוטיבציה לשיפור

פתרון אפשרי על ידי מיון: ניתן למיין את כל איברי המערך באמצעות אלגוריתם מיון יעיל (כגון MergeSort) בזמן \(\mathcal{O}(n \log n)\), ולאחר מכן להחזיר את האיבר במקום ה-\(i\).

החיסרון: מיון מלא פותר את הבעיה עבור כל \(i\) בו-זמנית — עבודה מיותרת כשאנו מעוניינים באיבר ספציפי אחד בלבד.

מציאת מינימום ומקסימום בזמן ליניארי \(\Theta(n)\):

minimum(A) n = length(A) min = A[1] for i = 1 to n if min > A[i] min = A[i] return min

המטרה שלנו בשיעור היא להכליל רעיון זה ולמצוא כל ערך מיקום \(i\) בזמן ליניארי \(\Theta(n)\).

3. אלגוריתם בחירה אקראית (Randomized-Select)

הפרד ומשול אקראי

האלגוריתם מתבסס על עקרון החלוקה של מיון מהיר (QuickSort):

  1. בוחרים איבר ציר (pivot) באקראי ומסדרים סביבו את המערך: הקטנים משמאל והגדולים מימין (randomized-partition).
  2. בניגוד ל-QuickSort שבו מפעילים רקורסיה על שני חלקי המערך, כאן מזהים באיזה צד נמצא האיבר ה-\(i\) וממשיכים רקורסיבית רק בחלק הרלוונטי.
randomized-select(A, p, r, i) if p == r return A[p] q = randomized-partition(A, p, r) k = q - p + 1 // מיקום הציר בתוך תת-המערך הנוכחי if i == k return A[q] else if i < k return randomized-select(A, p, q - 1, i) else return randomized-select(A, q + 1, r, i - k)

מעקב הרצה: מציאת האיבר ה-4 בגודלו במערך \([7, 3, 2, 1, 5, 9, 8]\)

  1. התחלה (\(n=7, i=4\)): נבחר באקראי \(\text{pivot} = 3\). לאחר חלוקה מתקבל \([1, 2, \mathbf{3}, 7, 5, 9, 8]\). הציר 3 נמצא במקום ה-\(k=3\). מכיוון ש-\(i=4 > 3\), פונים ימינה ומחפשים את האיבר ה-\(4 - 3 = 1\) (או לפי גרסת המרצה הכוללת את הציר: האיבר ה-2 בתת-המערך \([3, 7, 5, 9, 8]\)).
  2. שלב שני: נבחר באקראי \(\text{pivot} = 7\). לאחר סידור מחדש והמשך צמצום הטווח, נבחר \(\text{pivot} = 5\).
  3. בסיס הרקורסיה: מגיעים לתת-מערך בגודל 1 המכיל רק את האיבר \(5\), וזהו הפתרון המוחזר.

תרגילים בנושא בחירה אקראית:

א. מדוע בפנייה לחלק הימני מעדכנים את האינדקס המבוקש ל-\(i - k\)?

מכיוון שבתת-המערך הנוכחי יש \(k\) איברים הקטנים או שווים לאיבר הציר בצד שמאל, כאשר אנו משליכים את כל החלק השמאלי, האיבר שהיה במקום ה-\(i\) מתוך כלל המערך הנוכחי הופך כעת לאיבר במקום ה-\(i - k\) בתוך תת-המערך הימני החדש.

ב. מה תפקיד הפקודה swap(A[k], A[r]) בתחילת הפונקציה randomized-partition?

היא מעבירה את איבר הציר שנבחר באקראי לסוף תת-המערך (אינדקס \(r\)), כדי שנוכל להריץ את לולאת החלוקה הרגילה של QuickSort (אשר מניחה שאיבר הציר נמצא בסוף הטווח) ללא צורך בשינוי קוד הלולאה.

4. ניתוח זמנים: Randomized-Select

מקרה טוב, גרוע וממוצע

זמן הריצה של האלגוריתם האקראי תלוי באיכות החלוקה שמייצר איבר הציר בכל שלב:

תרחיש תיאור החלוקה נוסחת נסיגה \(T(n)\) סיבוכיות סופית
מקרה טוב (Best Case) הציר הוא תמיד החציון (חלוקה לשניים בגודל \(\frac{n}{2}\)) \(T(n) = T(n/2) + cn\) \(\Theta(n)\)
מקרה גרוע (Worst Case) הציר הוא תמיד המקסימום או המינימום (חלוקה ל-\(1\) ו-\(n-1\)) \(T(n) = T(n-1) + cn\) \(\Theta(n^2)\)
מקרה ממוצע (Average Case) מיצוע על פני כל בחירות הציר האקראיות האפשריות ניתוח הסתברותי (תוחלת) \(\mathcal{O}(n)\)

תרגילים בניתוח זמנים:

א. פתח את נוסחת הנסיגה של המקרה הטוב \(T(n) = T(n/2) + cn\) והוכח שהיא שווה ל-\(\Theta(n)\).
\[ T(n) = T\left(\frac{n}{2}\right) + cn = T\left(\frac{n}{4}\right) + c\left(\frac{n}{2} + n\right) = \dots = c\left(1 + \dots + \frac{n}{4} + \frac{n}{2} + n\right) \]

זהו טור הנדסי יורד שסכומו חסום מלמעלה על ידי \(2cn\), ולכן \(T(n) = \Theta(n)\).

ב. פתח את נוסחת הנסיגה של המקרה הגרוע \(T(n) = T(n-1) + cn\) והוכח שהיא שווה ל-\(\Theta(n^2)\).
\[ T(n) = T(n-1) + cn = T(n-2) + c(n + (n-1)) = \dots = c(1 + 2 + \dots + n) = c \cdot \frac{n(n+1)}{2} \]

מכיוון שהחזקה הדומיננטית היא \(n^2\), זמן הריצה במקרה הגרוע הוא \(\Theta(n^2)\).

5. אלגוריתם דטרמיניסטי: חציון החציונים (Select)

בחירה חכמה ומאוזנת

כדי להבטיח זמן ריצה ליניארי \(\mathcal{O}(n)\) גם במקרה הגרוע ביותר, עלינו לבחור איבר ציר בצורה חכמה ודטרמיניסטית שתבטיח חלוקה מאוזנת בכל שלב.

שלבי האלגוריתם select(A, p, r, i):

  1. חלוקה לחמישיות: מחלקים את מערך הקלט \(A\) לקבוצות בנות 5 איברים כל אחת (סה"כ \(\lceil n/5 \rceil\) קבוצות).
  2. מציאת חציונים מקומיים: ממיינים כל חמישייה ומוצאים את החציון שלה. אוספים את כל החציונים למערך עזר \(B\) (בגודל \(\lceil n/5 \rceil\)).
  3. מציאת חציון החציונים: מפעילים את הפונקציה select באופן רקורסיבי על המערך \(B\) כדי למצוא את החציון שלו — איבר זה יוגדר בתור ה-pivot.
  4. חלוקת המערך: מבצעים q = partition(A, p, r, pivot) סביב איבר הציר שנמצא.
  5. רקורסיה על החלק המתאים: בודקים היכן נמצא האיבר ה-\(i\) ביחס לאינדקס \(q\) וממשיכים רקורסיבית רק בחלק השמאלי או הימני.

המחשה עבור 100 מספרים (20 עמודות של 5 איברים):

  • מסדרים כל עמודה בת 5 מספרים מהקטן לגדול (מלמעלה למטה), ומסדרים את העמודות משמאל לימין לפי גודל החציונים בשורה האמצעית.
  • איבר הציר שנבחר הוא חציון השורה האמצעית (בדוגמה שבמצגת: המספר 47).
  • איברים קטנים מהציר: כל החציונים משמאל ל-47 קטנים ממנו, וכל האיברים שמעליהם בעמודותיהם קטנים מהם — לכן מובטחת קבוצה גדולה של איברים שקטנים או שווים ל-47.
  • איברים גדולים מהציר: באופן סימטרי, כל החציונים מימין ל-47 וכל האיברים שמתחתיהם בעמודותיהם גדולים או שווים ל-47.

6. ניתוח גודל הקבוצות והוכחת ליניאריות במקרה הגרוע

הוכחה מתמטית

חישוב גודל הקבוצות שנוצרות לאחר החלוקה:

  • ישנן \(\lceil n/5 \rceil\) קבוצות של 5, ולכן ישנם \(\lceil n/5 \rceil\) חציונים.
  • מכיוון ש-pivot הוא חציון החציונים, לפחות מחצית מהחציונים גדולים או שווים לו: \(\lceil \frac{1}{2} \lceil n/5 \rceil \rceil\).
  • בכל קבוצה כזו (למעט לכל היותר 2 קבוצות קצה: הקבוצה של הציר עצמו, וקבוצה אחרונה שאולי אינה מלאה ב-5 איברים) יש לפחות 3 איברים שגדולים מ-pivot.
\[ \text{מספר האיברים הגדולים מ-pivot לפחות:} \quad \left(\left\lceil \frac{1}{2} \left\lceil \frac{n}{5} \right\rceil \right\rceil - 2\right) \cdot 3 \ge 3\left(\frac{n}{10} - 2\right) = \frac{3}{10}n - 6 \]

מכאן נובע שמספר האיברים הקטנים מ-pivot (החלק שיישאר לרקורסיה במקרה הגרוע) הוא לכל היותר:

\[ n - \left(\frac{3}{10}n - 6\right) = \frac{7}{10}n + 6 \]

באופן סימטרי לחלוטין, גם מספר האיברים הגדולים מ-pivot הוא לכל היותר \(\frac{7}{10}n + 6\). כלומר, בכל שלב אנו משליכים לפחות 30% מהקלט!

בניית משוואת הנסיגה הכוללת:

  • שלבים 1, 2 ו-4 (חלוקה לחמישיות, מיון כל חמישייה בזמן קבוע \(\mathcal{O}(1)\), וביצוע partition): סה"כ \(\mathcal{O}(n)\).
  • שלב 3 (קריאה רקורסיבית למציאת חציון החציונים במערך \(B\)): \(T(\lceil n/5 \rceil)\).
  • שלב 5 (קריאה רקורסיבית על החלק המתאים): לכל היותר \(T(7n/10 + 6)\).
\[ T(n) \le T\left(\frac{n}{5}\right) + T\left(\frac{7}{10}n + 6\right) + \mathcal{O}(n) \implies T(n) = \mathcal{O}(n) \]

תרגילים בנושא אלגוריתם חציון החציונים:

א. מדוע סכום הגדלים של שתי הקריאות הרקורסיביות במשוואה מבטיח זמן ריצה ליניארי \(\mathcal{O}(n)\)?

סכום הגדלים של תתי-הבעיות הרקורסיביות הוא \(\frac{1}{5}n + \frac{7}{10}n = \frac{9}{10}n = 0.9n\). מכיוון ש-\(0.9n < n\) (העבודה יורדת גאומטרית בכל רמה בעץ הרקורסיה), מתקבל טור הנדסי מתכנס שסכומו פרופורציונלי לעבודה בשורש העץ, ולכן הפתרון הוא \(\mathcal{O}(n)\).

ב. מה יקרה אם נחלק את המערך לשלשות (קבוצות בגודל 3) במקום לחמישיות? האם האלגוריתם יישאר ליניארי?

לא! אם נחלק לקבוצות של 3, מציאת חציון החציונים תיקח \(T(n/3)\). בכל קבוצה שחציונה קטן מהציר יש רק 2 איברים קטנים מהציר, ולכן לפחות \(\frac{1}{2} \cdot \frac{n}{3} \cdot 2 = \frac{n}{3}\) איברים קטנים ממנו, מה שמשאיר עד \(\frac{2}{3}n\) איברים להמשך הרקורסיה.

\[ T(n) \le T\left(\frac{n}{3}\right) + T\left(\frac{2}{3}n\right) + \mathcal{O}(n) \]

כאן \(\frac{1}{3}n + \frac{2}{3}n = n\) (העבודה נשארת קבועה בכל רמה), ולכן נקבל \(\mathcal{O}(n \log n)\) ולא זמן ליניארי.
