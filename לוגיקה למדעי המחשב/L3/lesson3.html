1. הגדרת קריאות יחידה (Unique Readability)

הגדרת יסוד

בשפות פורמליות ולוגיות, אנו דורשים שלכל פסוק מורכב יהיה פירוש ויזואלי ותחבירי יחיד וחד-משמעי.

הגדרה: נתון מבנה אינדוקטיבי C(B, K) כאשר B קבוצת הבסיס ו-K קבוצת האופרטורים. נאמר ש-C בעל קריאות יחידה אם לכל X ∈ C מתקיים בדיוק אחד מהתנאים הבאים:
  • תנאי 1 (אטומי): X ∈ B (אינו נוצר ע"י אופרטורים, אלא איבר בסיסי בלבד).
  • תנאי 2 (מורכב): קיימים אברים יחידים a1, a2, ..., an ∈ C ואופרטור יחיד f ∈ K כך ש-X = f(a1, a2, ..., an).

למה זה חשוב?

ללא קריאות יחידה, אותה מחרוזת תווים תוכל להתפרש ככמה עצי גזירה שונים, דבר שיגרום לסתירות בקביעת ערך האמת של הפסוק. אנו נדרשים להוכיח שכל פסוק מקבל ייצוג יחיד במבנה העץ שלו.

2. דוגמה למבנה ללא קריאות יחידה ומשפט הפסוקים

דוגמה נגדית ומשפט

דוגמה נגדית: יהי B = {0} ו-K = {f(x)=x+1, g(x)=x-2}.

ניתן להגיע למספר 1 ∈ C בשתי דרכים שונות לגמרי:

1) f(0) = 0 + 1 = 1
2) f(f(f(g(0)))) = 0 - 2 + 1 + 1 + 1 = 1

מכיוון שהדרך אינה יחידה, המבנה אינו בעל קריאות יחידה.

משפט קריאות היחידה של קבוצת הפסוקים בכתיב מלא: לכל פסוק α מתקיים בדיוק אחד מהתנאים הבאים (זרות מוחלטת ויחידות):
  1. α ∈ B (פסוק אטומי).
  2. קיים γ יחיד כך ש-α = (¬ γ).
  3. קיימים γ, δ יחידים וקשר בינארי @ יחיד כך ש-α = (γ @ δ).

3. 3 הוכחות היחידות מהמחברת (שלב אחר שלב)

הוכחות מפורטות מהמרצה

כדי להוכיח את משפט קריאות היחידה במלואו, המרצה מוכיח 3 מקרים שונים המכסים את כל סוגי ההשוואות בין מבני הפסוקים האפשריים:

מקרה ①: יחידות הייצוג עבור קשר אונארי (α = (¬ γ))

הטענה להוכחה: יהי α = (¬ γ). נוכיח שלא ייתכן כי α = (¬ φ) כאשר γ ≠ φ.

מהלך ההוכחה מתוך ניתוח עץ התווים במחברת:

נשווה את שני הפירוקים המוצעים למחרוזת α:

(¬ φ) = (¬ γ)

נפרק את התווים במחרוזת משמאל לימין באמצעות פונקציית מיקום התווים (charAt):

  • התו הראשון משמאל: str.charAt(0) ⇒ '(' = '(' (סוגר שמאלי בשני הצדדים).
  • התו השני: charAt(1) ⇒ '¬' = '¬' (סימן השלילה בשני הצדדים).
  • התו האחרון מימין: charAt(len-1) ⇒ ')' = ')' (סוגר ימני בסוף בשני הצדדים).
  • המסקנה התחבירית: התווים שנותרו באמצע חייבים להיות זהים לחלוטין! כלומר φ = γ.

קיבלנו שכל פירוק נוסף יוביל בהכרח לכך ש-φ ו-γ הם בדיוק אותו הפסוק, בסתירה להנחה ש-γ ≠ φ. לכן, הייצוג של קשר אונארי הוא יחיד!

מקרה ②: אי-אפשרות לחפיפה בין קשר אונארי לקשר בינארי

הטענה להוכחה: יהי α = (¬ γ). נוכיח שלא קיימים φ, ψ וקשר בינארי @ כך ש-α = (φ @ ψ).

מהלך ההוכחה מתוך ניתוח התווים במחברת:

נניח בשלילה כי אותה מחרוזת α יכולה להיכתב בשתי הצורות:

(¬ γ) = (φ @ ψ)

נבדוק את התווים בתחילת המחרוזת לפי השוואת אינדקסים (charAt):

  • התו הראשון: charAt(0) ⇒ '(' = '(' (תואם בשני הצדדים).
  • התו השני: באגף שמאל התו השני הוא הסימן '¬', ואילו באגף ימין התו השני הוא התו הראשון של הפסוק φ, כלומר φ.charAt(0).
  • בסוגריים מתקבל: ¬ = φ.charAt(0).

הסתירה: שום פסוק תקין בכתיב מלא לא יכול להתחיל בסימן שלילה '¬' ללא סוגריים פותחים לפניו (מכיוון ששלילה תמיד מוקפת בסוגריים כגון (¬ ...)). לכן הפסוק φ אינו חוקי, בסתירה לכך ש-φ הוא פסוק תקין. לא ייתכן שפסוק בינארי ופסוק אונארי יזדהו!

מקרה ③: יחידות הייצוג עבור קשר בינארי (α = (γ @ δ))

הטענה להוכחה: יהי α = (γ @ δ). נוכיח שלא ייתכן פירוק שונה α = (φ * ψ) עבור φ ≠ γ, ψ ≠ δ, או * ≠ @.

מהלך ההוכחה מתוך ניתוח עץ הפירוק במחברת:

נשווה את שני הביטויים הבינאריים:

(φ * ψ) = (γ @ δ)

נסיר את הסוגר השמאלי הפותח charAt(0):

φ * ψ) = γ @ δ)

כעת נבחן את היחס בין המחרוזות φ ו-γ:

  • אם φ ≠ γ, אזי אחת המחרוזות חייבת להיות רישא ממש של השנייה (למשל, φ = γ' כאשר γ' היא רישא ממש של γ).
  • לפי המשפט שהוכחנו בהרצאה: רישא ממש של פסוק תקין אינה יכולה להיות פסוק תקין בעצמה (חוסר איזון בסוגריים).
  • לכן, בהכרח מתחייב: φ = γ!
  • מכאן נובע שנשארנו עם: * ψ) = @ δ).
  • התו הבא בתור חייב להיות הקשר הבינארי, ולכן: * = @.
  • מצמצמים את הקשר ונותרים עם: ψ) = δ).
  • בסוף המחרוזת charAt(len-1), מורידים את הסוגר הימני וברור שמתקיים: ψ = δ.

מסקנה סופית: הוכחנו יחידות מלאה לכל 3 המקרים, ולכן לכל פסוק בשפת הפסוקים יש עץ בנייה ופירוק אחד ויחיד (מ.ש.ל)!

4. פונקציית האמת המורחבת (V̄)

סמנטיקה של פסוקים

פונקציית השמת אמת בסיסית מוגדרת על האטומים: V: P → {T, F}. הרחבתה לכלל הנוסחאות מסומנת ב-V̄: A → {T, F}.

כללי החישוב האינדוקטיביים:

  • α ∈ P ⇒ V̄(α) = V(α)
  • α = (γ ∨ δ) ⇒ V̄(α) = F אם ורק אם V̄(γ) = V̄(δ) = F
  • α = (γ ∧ δ) ⇒ V̄(α) = T אם ורק אם V̄(γ) = V̄(δ) = T
  • α = (¬ β) ⇒ V̄(α) = T אם ורק אם V̄(β) = F
  • α = (γ → δ) ⇒ V̄(α) = F אם ורק אם V̄(γ) = T וגם V̄(δ) = F

5. הגדרת גרירה לוגית (U ⊨ α)

גרירה סמנטית
הגדרה: תהי U קבוצת פסוקים ו-α פסוק. אומרים ש-U גוררת לוגית את α (ומסמנים U ⊨ α) אם לכל השמה V̄ המקיימת V̄(U) = T (כלומר מקיימת את כל אברי U), מתקיים בהכרח גם V̄(α) = T.
תרגיל: האם {p, p → q} ⊨ q?

פתרון מפורט: תהי V̄ השמה המקיימת את ההנחות. כלומר V̄(p) = T וגם V̄(p → q) = T. לפי הגדרת הגרירה, כדי ש-p → q יהיה אמת כאשר p אמת, חובה ש-V̄(q) = T. לכן ההסקה תקפה ומתקיים U ⊨ q.
