1. מבנה "המחשב הקטון" ורכיבי המעבד

שקופיות 72-73

כדי להבין איך מחשב פועל, אנו משתמשים במודל מופשט ("מחשב צעצוע") המבוסס על ארכיטקטורת פון ניומן:

  • הזיכרון הראשי (Memory): מערך רציף של תאים (למשל 100 תאים). לכל תא יש כתובת (0 עד 99) ותוכן (הוראה או נתון).
  • יחידת בקרה (Control Unit):
    • IP (Instruction Pointer): אוגר המחזיק את הכתובת של ההוראה הבאה לביצוע.
    • IR (Instruction Register): אוגר המחזיק את ההוראה הנוכחית שמפוענחת ומבוצעת.
  • יחידת ביצוע (ALU - Arithmetic Logic Unit):
    • DR1, DR2 (Data Registers): אוגרי נתונים פנימיים ומהירים המציבים נתונים לחישוב.
    • FR (Flags Register): אוגר דגלים השומר את תוצאת ההשוואה האחרונה.

מחזור ההוראה (Fetch-Execute Cycle):

כל הוראה עוברת שני שלבים מרכזיים:

  1. שלב ההבאה (Fetch): קריאת ההוראה מכתובת ה-IP לתוך ה-IR, וקידום אוטומטי של ה-IP לכתובת הבאה (\(IP \leftarrow IP + 1\)).
  2. שלב הביצוע (Execute): פענוח ההוראה שב-IR וביצוע הפעולה الנדרשת.

2. בקרה, קפיצות ותנאים (Jump / Jumptrue)

שקופיות 72-73 (סיכום)

קפיצות בקוד מאפשרות לממש מבני תנאי כמו If-Else או בלולאות:

  • jump addr: קפיצה ללא תנאי. מעדכנת ישירות את \(IP \leftarrow addr\).
  • jumptrue addr: קפיצה מותנית. הקפיצה מתבצעת רק אם ההשוואה הקודמת הצליחה.
הערת מרצה חשובה לגבי אוגר הדגלים (FR):
בהגדרת המרצה בהרצאה זו, הדגל 0 מסמן "אמת" (השוואה הצליחה) ו-1 מסמן "שקר".
מסלול \(A = B\) (התנאי מתקיים) מסלול \(A \neq B\) (התנאי לא מתקיים)
טעינת \(A, B\) לאוגרים DR1, DR2 טעינת \(A, B\) לאוגרים DR1, DR2
השוואה: דגל = 0 (אמת) השוואה: דגל = 1 (שקר)
jumptrue 06 מקפץ ל-06 jumptrue 06 לא מקפץ (ממשיך לשורה 4)
מבצע ענף If (\(A = 2\)) ואז end מבצע ענף Else (\(B = 2\)), ואז jump 07 ל-end
סה"כ 6 הוראות מבוצעות סה"כ 7 הוראות מבוצעות

חשיבות פקודת jump 07 בסוף ענף ה-Else:

לאחר ביצוע ענף ה-Else (בכתובת 4), המעבד נוטה להמשיך ברצף לכתובת 5 ולכתובת 6. אולם כתובת 6 מכילה את הקוד של ענף ה-If. כדי למנוע זליגה וביצוע כפול של שני הענפים, חייבים פקודת jump 07 שמדלגת ישירות לסוף התוכנית.

3. ארכיטקטורת פסים (HAS & Bus System)

שקופיות 74-75

ארכיטקטורת חומרה (HAS - Hardware System Architecture) ממתגת ומחברת את היחידות השונות (CPU, Memory, I/O) דרך פסים (Busses) – אוסף מוליכים חשמליים משותפים:

  • 1. פס הכתובות (Address Bus): מעביר כתובות זיכרון. כיוון הזרם: חד-כיווני (מה-CPU החוצה).
  • 2. פס הנתונים (Data Bus): מעביר נתונים והוראות בפועל. כיוון הזרם: דו-כיווני (מעבד \(\leftrightarrow\) זיכרון).
  • 3. פס הבקרה (Control Bus): מעביר אותות שליטה וסוג פעולה (כגון קריאה Read או כתיבה Write).

רוחב פס והשפעתו:

מספר המוליכים (החוטים) בפס קובע את כמות המידע או גודל הזיכרון שניתן לנהל:

  • פס כתובות של \(n\) חוטים יכול לייצג \(2^n\) כתובות שונות.
\[ \text{16-bit Address Bus} \implies 2^{16} = 65,536 \text{ locations (64 KB)} \] \[ \text{32-bit Address Bus} \implies 2^{32} \approx 4,294,967,296 \text{ locations (4 GB)} \]

4. מחזורי קריאה וכתיבה מהזיכרון

שקופיות 76-77

המעבד מתקשר עם הזיכרון באמצעות שני מחזורים מרכזיים:

א. מחזור קריאה (Read Cycle):

  1. המעבד שולח כתובת מבוקשת בפס הכתובות (למשל Address = 125).
  2. המעבד מפעיל אות קריאה בפס הבקרה (Read = 0, כאשר 0 פעיל - Active Low).
  3. הזיכרון מוציא את הנתון לפס הנתונים (Data = Memory[125]) והנתון זורם אל המעבד.

ב. מחזור כתיבה (Write Cycle):

  1. המעבד שולח כתובת יעד בפס הכתובות (למשל Address = 125).
  2. המעבד מציב את הנתון לכתיבה בפס הנתונים (למשל Data = 0). הנתון זורם מהמעבד אל הזיכרון.
  3. המעבד מפעיל אות כתיבה בפס הבקרה (Write = 0). הזיכרון שומר את הנתון בתא.
מאפיין מחזור קריאה (Read Cycle) מחזור כתיבה (Write Cycle)
פס הכתובות המעבד שולח כתובת \(\rightarrow\) לזיכרון המעבד שולח כתובת \(\rightarrow\) לזיכרון
פס הבקרה Read = 0 (Active Low) Write = 0 (Active Low)
פס הנתונים זיכרון \(\rightarrow\) מעבד (זרימה שמאלה) מעבד \(\rightarrow\) זיכרון (זרימה ימינה)

5. סינכרון ושעון פנימי (Clock & Frequency)

שקופיות 78-81

כדי לסנכרן את פעולת כל הרכיבים והפסים, המחשב משתמש בשעון פנימי (Internal Clock) המייצר גל ריבועי מתמיד (Square Wave):

  • מחזור שעון (Clock Cycle): משך הזמן שלוקח לגל לעלות מ-0 ל-1 ולרדת בחזרה ל-0.
  • תדר השעון (Frequency - \(f\)): מספר המחזורים בשנייה, נמדד בהרץ (Hz), MHz, או GHz.
  • זמן מחזור (\(T\)): מחושב לפי הנוסחה:
    \[ T = \frac{1}{f} \]
הבחנה קריטית: תדר המעבד \(\neq\) מספר ההוראות בשנייה!
מעבד ב-500MHz אינו מבצע 500 מיליון הוראות בשנייה, מפני שכל הוראה דורשת מספר מחזורי שעון, ופניות לזיכרון חיצוני (או I/O) דורשות מחזורי המתנה נוספים (למשל, במעבד 8086 גישה לזיכרון אורכת 4 מחזורי מכונה).

חישובי זמן מחזור לדוגמה:

  • במעבד בתדר \(f = 500 \text{ MHz}\):
    \[ T = \frac{1}{500 \times 10^6} = 2 \times 10^{-9} \text{ seconds} = 2 \text{ ns} \]
  • במעבד בתדר \(f = 3 \text{ GHz}\):
    \[ T = \frac{1}{3 \times 10^9} \approx 0.33 \times 10^{-9} \text{ seconds} = 0.33 \text{ ns} \]

מסקנה: ככל שהתדר גבוה יותר, זמן המחזור \(T\) קצר יותר והמעבד מתקתק מהר יותר.

6. אלגברת מיתוג - פונקציות נוספות

שקופית 4

בנוסף לפונקציות הבסיסיות (AND, OR, NOT), קיימות פונקציות מורכבות ומשלימות שימושיות מאוד:

  • NAND: פונקציה משלימה ל-AND (עבור (A · B)¯). מוציאה 0 רק כששתי הכניסות הן 1.
  • NOR: פונקציה משלימה ל-OR (עבור (A + B)¯). מוציאה 1 רק כששתי הכניסות הן 0.
  • XOR (Exclusive OR): "או מוציא" (A ⊕ B). מוציאה 1 כאשר הכניסות שונות זו מזו.
  • XNOR: פונקציה משלימה ל-XOR (עבור (A ⊕ B)¯). מוציאה 1 אך ורק כאשר שני המשתנים זהים (00 או 11).

טבלת אמת השוואתית לפונקציות הנוספות:

A B NAND ((A · B)¯) NOR ((A + B)¯) XOR (A ⊕ B) XNOR ((A ⊕ B)¯)

7. רכיבים לוגיים (שערים)

שקופית 5

שערים לוגיים (Logic Gates) הם רכיבי היסוד הפיזיים של כל מערכת ספרתית, המממשים את פונקציות המיתוג ברמת החומרה:

  • שער AND: מבנה בצורת האות D. מוציא A · B.
  • שער OR: גב קעור וחזית מחודדת. מוציא A + B.
  • שער NOT (מהפך): משולש עם עיגול בקצה המוצא. מוציא Ā.
  • העיגול (Bubble) בסמל: מייצג היפוך לוגי (NOT). הוספת עיגול במוצא של AND נותנת NAND, ובמוצא של OR נותנת NOR.

כלל אצבע לזיהוי שערים:

  • NAND = AND + Bubble במוצא ⇒ (A · B)¯
  • NOR = OR + Bubble במוצא ⇒ (A + B)¯
  • XNOR = XOR + Bubble במוצא ⇒ (A ⊕ B)¯

8. אלגברה בוליאנית - זהויות במשתנה אחד

שקופית 6

חוקים בסיסיים לפישוט ביטויים בוליאניים עבור משתנה בודד A:

פעולת AND פעולת OR פעולת NOT
A · 0 = 0 A + 0 = A (Ā)¯ = A
A · 1 = A A + 1 = 1
A · A = A A + A = A
A · Ā = 0 A + Ā = 1

עקרון הדואליות (Dual Principle):

כל זהות תקפה נשמרת אם מחליפים כל פעולת AND (·) בפעולת OR (+), וכל 0 ב-1 (ולהפך).

A · 1 = A   ⇔   A + 0 = A
A · Ā = 0   ⇔   A + Ā = 1

9. זהויות בשני משתנים ויותר

שקופית 7

חוקי האלגברה הבוליאנית עבור שני משתנים או יותר:

  • כללי דה-מורגן (DeMorgan): (A · B)¯ = Ā + B̄,   (A + B)¯ = Ā · B̄
  • כללי החילוף (Commutative): A + B = B + A,  A · B = B · A
  • כללי הקיבוץ (Associative): A + (B + C) = (A + B) + C,  A · (B · C) = (A · B) · C
  • כללי הבליעה (Absorption): A + (A · B) = A,  A · (A + B) = A
  • כללי הפילוג (Distributive):
    A · (B + C) = (A · B) + (A · C)
    A + (B · C) = (A + B) · (A + C)

הוכחת (A · B)¯ = Ā + B̄ בטבלת אמת:

A B A · B (A · B)¯ Ā B̄ Ā + B̄

1001011

רואים בבירור כי העמודה של (A · B)¯ זהה לחלוטין לעמודה של Ā + B̄.

10. כללי צימצום באלגברה בוליאנית

שקופית 8

קיצורי דרך מרכזיים לפישוט מהיר של ביטויים בוליאניים:

כלל 1: X + (X · Y) = X
כלל 2: X · (X + Y) = X
כלל 3: X + X̄ · Y = X + Y
כלל 4: X · (X̄ + Y) = X · Y

הוכחת X + X̄ · Y = X + Y בעזרת פילוג:

X + X̄ · Y = (X + X̄) · (X + Y)
= 1 · (X + Y) = X + Y

12. ייצוג אלגברי וצמצום מעגלים

שקופית 10

ייצוג אלגברי של פונקציה בוליאנית אינו יחיד. ביטויים אלגבריים שונים לחלוטין יכולים לייצג בדיוק את אותה טבלת אמת.

הוכחת שוויון אלגברי:

נתונות הפונקציות F3 = x̄ ȳ z + x̄ y z + x ȳ ו-F4 = x ȳ + x̄ z:

F3 = x̄ z (ȳ + y) + x ȳ = x̄ z · 1 + x ȳ = x̄ z + x ȳ = F4

13. מימוש פונקציות בעזרת שערים לוגיים

שקופית 11

פישוט ביטוי בוליאני מוביל באופן ישיר לחיסכון במספר השערים ובמספר הכניסות לשערים בחומרה:

  • מימוש F3 המקורית דרש 6 שערים (חלקם עם 3 כניסות).
  • מימוש F4 המצומצמת דורש 5 שערים בלבד (כולם עם 2 כניסות).

יתרונות הפישוט בחומרה:

מעגל מצומצם תופס פחות שטח רכיב בסיליקון, צורך פחות הספק חשמלי, מייצר פחות חום, ופועל במהירות גבוהה יותר.

14. מערכת פעולות שלמה

שקופית 24

קבוצת אופרטורים נקראת "מערכת שלמה" אם ניתן לתאר וליצור באמצעותה כל פונקציית מיתוג אפשרית:

  • {AND, OR, NOT} היא מערכת שלמה.
  • {AND, NOT} ו-{OR, NOT} הן מערכות שלמות (לפי דה-מורגן).
  • שער NAND לבדו או שער NOR לבדו מהווים כל אחד מערכת שלמה יחידה!

בניית פעולות יסוד באמצעות שער NAND בלבד:

NOT: Ā = NAND(A, A)
AND: A · B = NOT(NAND(A, B))
OR: A + B = NAND(Ā, B̄)

16. צמצום מעגל חצי-מסכם

שקופית 27

על ידי שיתוף רכיבים אלגברי, ניתן לצמצם את מעגל החצי-מסכם מ-6 שערים ל-4 שערים בלבד:

S = (A · B)¯ · (A + B)
C = ((A · B)¯)¯ = A · B

במעגל זה משתמשים בשער NAND אחד שמחשב את (A · B)¯, והתוצאה שלו משמשת גם לחישוב S וגם לחישוב C (בעזרת שער NOT).

ארבעת השערים במעגל הממוטב:

  1. שער OR שמחשב את A + B.
  2. שער NAND שמחשב את (A · B)¯.
  3. שער AND שמחבר את שניהם ומפיק את S = (A · B)¯ · (A + B).
  4. שער NOT ההופך את מוצא ה-NAND ומפיק את C = A · B.

17. שלבים בתכנון מעגל לוגי

שקופית 28

מתודולוגיית העבודה התקנית לתכנון מעגל ספרתי:

  1. הגדרת הבעיה: במילים או באמצעות טבלת אמת.
  2. רישום ביטוי בוליאני: חילוץ הפונקציות מתוך הטבלה.
  3. פישוט הביטוי: אופטימיזציה של מספר השערים וסוגי השערים.
  4. שרטוט המעגל: סרטוט הדיאגרמה הלוגית הסופית.

דוגמה מעשית מתהליך החצי-מסכם:

1. הגדרה (חיבור 2 סיביות) → 2. טבלת אמת וביטויים (S = Ā B + A B̄, C = A · B) → 3. פישוט ל-4 שערים → 4. שרטוט המעגל הסופי.
